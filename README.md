# 学位英语 50 题冲刺网站 v3.1

一个无需账号的静态网站：774 道原创仿真练习组成题库，每套抽取 50 道题并均衡打乱 A/B/C/D 正确答案位置。题目、作答记录、计时、最近 10 套历史、掌握状态和导出报告默认只留在浏览器本机。每次交卷会保存整套 50 题、当时的选项顺序、你的选择、“不会”标记、正确答案和错题解析。完成后复制错题报告到与教练的对话，由教练逐题讲解。

v3.1 在 v3 的错题强化、不会标记、掌握状态、题内单词解释、学习档案导入导出和 PWA 离线缓存基础上，补全了整套试题记录。发布到 HTTPS 网站后，可从浏览器添加到手机主屏幕。

题目属于依据公开考试结构编写的原创仿真练习，不冒充历年真题，也不能替代学校发布的考试说明。

## 本地使用

直接双击 `index.html`，或在该目录启动任意静态服务器后打开。手机与电脑须分别保存自己的本地进度。

## 发布到 GitHub Pages

1. 新建一个**公开** GitHub 仓库，例如 `degree-english-sprint`。
2. 上传此目录中全部文件，保持 `index.html` 在仓库根目录。
3. 在仓库 Settings → Pages 选择 Deploy from a branch，选择 `main` 与 `/ (root)`，保存。
4. 等待 GitHub 给出站点地址；用手机浏览器打开并“添加到主屏幕”。

注意：GitHub Pages 为公开静态站点，仓库内的网页代码与题目会公开；学习记录仍只保留在使用者浏览器。

## 换设备

在旧设备首页点击“导出学习档案”，把 `.json` 文件发送到新设备；在新设备打开同一网站后点击“导入学习档案”。这属于手动迁移，不是服务器自动同步。
