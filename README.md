# 学位英语考前冲刺网站 v4.2

一个无需账号的静态网站：791 道原创仿真练习组成题库，围绕“模拟测评 → 薄弱强化 → 重点复测”安排考前任务。每套模拟测评抽取 50 道题并均衡打乱 A/B/C/D 正确答案位置。题目、作答记录、计时、最近 10 套历史、掌握状态和导出报告默认只留在浏览器本机。

v4.2 新增“零基础语法急救”独立讲解页，第一篇用主语、助动词、时间词和固定搭配把 `go / goes` 讲透，并提供发音与5题即时自测。入口位于首页且不会覆盖未完成的练习状态；手机端按单列阅读、44px 以上点击区和明确区块间距排版。v4.1 已完成的真实英文听读、均衡抽题、同考点强化与分日冲刺计划继续保留。

考试得分与掌握度继续分开：“答对但标记不确定”仍计入考试得分，同时进入重点复习。曾经答错或标记不会的题，需要连续两次稳定答对后才恢复为“正确”。旧版学习记录、未完成题号和答案沿用原存储键，不会因本次升级清空。

题目属于依据公开考试结构编写的原创仿真练习，不冒充历年真题，也不能替代学校发布的考试说明。

## 本地使用

直接双击 `index.html`，或在该目录启动任意静态服务器后打开。手机与电脑须分别保存自己的本地进度。

## 发布到 GitHub Pages

1. 新建一个**公开** GitHub 仓库，例如 `degree-english-sprint`。
2. 上传此目录中全部文件，保持 `index.html` 在仓库根目录。
3. 在仓库 Settings → Pages 选择 Deploy from a branch，选择 `main` 与 `/ (root)`，保存。
4. 等待 GitHub 给出站点地址；用手机浏览器打开并“添加到主屏幕”。

注意：GitHub Pages 为公开静态站点，仓库内的网页代码与题目会公开；学习记录仍只保留在使用者浏览器。

## 换设备

在旧设备首页点击“导出学习档案”，把 `.json` 文件发送到新设备；在新设备打开同一网站后点击“导入学习档案”。这属于手动迁移，不是服务器自动同步。
